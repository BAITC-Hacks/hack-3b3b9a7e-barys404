# Фронтенд

React + TypeScript + Vite. Здесь нет обучения моделей, чтения CSV или SQL.

- `src/App.tsx`: страницы, навигация, фильтры и состояния запросов.
- `src/api.ts`: HTTP-клиент и типы ответов.
- `src/styles.css`: оформление и адаптивная сетка.
- `public/`: исходные публичные ресурсы.
- `dist/`: сгенерированная сборка; исключена из Git.
- `node_modules/`: установленные зависимости; исключены из Git.

```bash
npm ci
npm run dev
npm run build
```

Запускайте из `frontend/`. При разработке `/api` проксируется в FastAPI на порт 8000. Готовую сборку отдаёт `backend/api/main.py`; отдельный Node-сервер для демо не нужен.
